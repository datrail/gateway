# DatRail Gateway

An enforcement point that reads the `x-rail` ticket on an agent's MCP calls and
decides, against policy published by Rail Center, whether each one reaches the
service behind it.

[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security reports go to
[SECURITY.md](SECURITY.md) rather than a public issue.
